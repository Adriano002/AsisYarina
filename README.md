 Sistema de Control de Asistencia Escolar
Sistema web para el registro y gestión de asistencia de la I.E. Yarinacocha, desarrollado con Streamlit y PostgreSQL.
 Características
- Registro de asistencia por código QR o lista por sección
- Control de tardanzas con reglas institucionales (1ª/2ª perdonadas, 3ª → TOECE, 4ª+ → retenido)
- Gestión de actas de compromiso
- Lista de alumnos observados
- Reportes en PDF y Excel
- Generación de carnets con QR
- Panel de dirección con gráficos
- Sistema de roles (Admin, TOECE, Auxiliar, Dirección)
